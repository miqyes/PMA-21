# Лабораторна робота №8 - Структура

В цій роботі використано структуру для опису студента. Студент містить ім'я, прізвище, дату народження та список оцінок.

## Що робить програма
Програма зчитує студентів з файлу `input.txt`, створює для кожного студента структуру `Student` і перевіряє, чи склав студент сесію.

Студент вважається таким, що не склав сесію, якщо має хоча б одну оцінку меншу за 51.

## Запуск
Щоб запустити через консоль:
```bash
dotnet run --project Lab-8.csproj
```
