# Лабораторна робота №7 - Абстракція

В цій роботі реалізовано шаблон проектування Bridge. Програма має дві окремі ієрархії: фігури та кольори.

## Що робить програма
Програма створює фігури та задає для них колір через окрему абстракцію.

У роботі реалізовано три фігури:
- коло
- прямокутник
- квадрат

Також реалізовано три кольори на вибір.

Кожна фігура має свій колір і може обчислювати:
- периметр
- площу

Шаблон Bridge використано для того, щоб відокремити фігури від кольорів. Завдяки цьому фігури і кольори можна змінювати незалежно одне від одного.
