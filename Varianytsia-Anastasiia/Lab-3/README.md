# Лабораторна робота 3 - Калькулятор матриць

Ця лабораторна - це калькулятор для матриць. Тут все зроблено через звичайні двомірні масиви `double[,]` і статичні методи, без класів для самої матриці.

## Шо робить програма
Програма бере дві матрици з текстових файлів і рахує:
- Додавання
- Віднімання 
- Множення 
- Ділення 

Всі результати записуються в окремий файл.

## Запуск
Шоб запустити через консоль:
```bash
dotnet run --project Lab-3.csproj
```
