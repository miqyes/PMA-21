# Лабораторна робота №6 - ArrayList

В цій роботі реалізований власний список ArrayList через класи. Список побудований на основі простого масиву.

## Що робить програма
Програма бере числа з файлу, записує їх у ArrayList і виконує над ним операції:
- Додавання елемента в кінець
- Вставка елемента за індексом
- Видалення елемента за індексом
- Видалення елемента за значенням
- Очищення списку

Якщо у масиві не вистачає місця, він розширюється до розміру 1,5 * x + 1, де x - поточний розмір масиву. Старі елементи копіюються в новий масив.

Всі кроки і результати записуються в окремий файл.

## Запуск
Щоб запустити через консоль:
```bash
dotnet run --project Lab-6.csproj
```
