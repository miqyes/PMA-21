# Лабораторна робота 5 - Калькулятор векторів

В цій лабораторній роботі реалізований калькулятор для векторів через класи. 

## Шо робить програма
Програма бере два вектори з файлу і рахує:
- Додавання
- Віднімання 
- Множення 
- Ділення 

Всі результати записуються в окремий файл.

## Запуск
Шоб запустити через консоль:
```bash
dotnet run --project Lab-5.csproj
```
